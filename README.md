# 📚 六级背单词 App

一个运行在本地 Mac 上的六级英语背单词应用，零第三方依赖，双击即可使用。

## ✨ 功能

| 功能 | 说明 |
| --- | --- |
| 🇬🇧→🇨🇳 英译中 | 看英文单词，从 4 个选项中选中文释义 |
| 🇨🇳→🇬🇧 中译英 · 选择 | 看中文释义，从 4 个选项中选英文单词 |
| 🎧 听写 | 听英文读音，输入单词；可反复播放，提交后显示正确单词、音标、词性、释义及读音按钮 |
| ✍️ 中译英 · 拼写 | 看中文释义，直接输入英文单词（可看音标提示） |
| 🃏 卡片模式 | 翻卡片回忆释义，点「认识 / 不认识」 |
| ✅ 已学单词 | 自动收录整组三轮测试全部通过的单词，支持搜索、到期/错词筛选、学习记录查看和单词/批量复习 |
| 📒 我的错题本 | 答错的词自动收集；可标记「已掌握 / 学习中」，支持单独复习 |
| ⭐ 收藏 | 手动收藏，支持多栏目分类、筛选和复习，与错题本独立 |
| 📖 全部词表 | 2219 个六级词，支持搜索、手动收藏 |
| 📊 学习统计 | 已学单词数、今日进度、正确率、最近 7 天柱状图 |
| ⚙️ 设置 | 每日目标、自定义添加单词、批量导入词表、数据备份/恢复 |
| 🧠 间隔复习 | 根据答题结果自动安排复习时间，优先练习到期词和易错词 |
| 🔊 单词朗读 | 优先播放有道词典在线美式音频（需联网），不可用时提示并回退到系统英文语音 |

## 🚀 如何启动

1. 进入本文件夹 `word`
2. **双击 `启动背单词.command`**（首次如提示安全警告，在「系统设置 → 隐私与安全性」中允许）
3. 浏览器会自动打开 `http://127.0.0.1:8765`，开始学习！

> 停止：在启动的终端窗口按 `Ctrl+C`。
> 也可手动启动：`python3 server.py --open`

## 📝 词库

- 内置 **2219 个六级核心词汇**（含音标、词性、中文释义），来源：公开的六级词汇表（`data/CET6_edited_raw.txt`）。
- 在「设置」中可以 **手动添加单词**，或 **批量导入** 自定义词表（每行一个：`单词 [音标] 释义` 或 `单词 释义`）。
- 自定义词会一并参与学习，并标记为「自定义」。
- 自定义词可以在「词表」中编辑或删除。

## 💾 数据存储

- 学习进度、错题本、统计都保存在浏览器的本地存储（localStorage）中，不会上传任何数据。
- 建议定期在「设置 → 数据备份 → 导出学习数据」保存一份 JSON 备份；换电脑/清缓存后可「导入学习数据」恢复。
- 备份文件带有数据版本并会在导入时校验，旧版有效备份仍可自动迁移。

## 先记忆，再测试

选择第一轮选择题方向、学习范围和数量（默认 20，可自定义），点击开始学习后会先显示完整单词表，包含英文、音标、释义和朗读按钮。记忆完成后点击「记好了，开始测试」，依次对整组做选择题、听写题和拼写题。听写题整组展示，每题可点击播放英文读音并重听，提交前不显示单词、音标和中文释义，批改后显示完整答案（含音标、词性、释义和读音按钮）。听写和拼写均填写整组后统一提交，逐题显示判定结果；漏填时会提示补全；每轮结束后只补测答错的词，仍答错则继续补测，直到该轮所有单词答对才进入下一阶段。三阶段均通过后才显示完成结果。错题本复习和重练错词使用同样流程。预习不增加答题数，所有实际作答（含补测）计入统计，结果页保留累计正确率和曾答错的词。

已学单词、错题本和收藏支持选择复习 / 测试单词数：10、20、30、50、全部或自定义正整数；不足所选数量时使用全部可用单词。已学单词按当前筛选和排序取词，错题本按当前搜索、状态和排序取词；收藏还支持按栏目筛选。所选单词依次参加三轮测试。

预习页的「返回调整」、测试页的「返回」及完成页的「返回」会回到本次学习的入口（已学单词、错题本、收藏或学习设置），保留筛选、数量和滚动位置。测试中返回会先确认，已作答记录保留。

今日进度与每日目标按当天完整通过整组三轮测试的不同单词计数，同一词一天只计 1 词。最后一轮补测通过并提交时即计入，无需再点击查看结果；中途退出只保留答题和错词记录，不新增已学或今日完成数量。未完成的词仍可从“未完成学习的单词”重新学习；已完成的词再次复习中途退出不会撤销原有完成记录；跨天自动更新。答题总次数、正确率和最近 7 天练习量仍按实际作答统计。

旧版仅记录作答，无法可靠区分完整完成与中途退出，因此旧答题、错词和正确率记录保留；已学与今日完成数量从有明确完成记录的测试开始计算。

## ⌨️ 快捷键

- 选择题可使用 `1`～`4` 或 `A`～`D` 作答。
- 选择题看完反馈后可按 `Enter` 或空格进入下一题。
- 整组听写和拼写：`Tab` 跳到下一词，`Shift + Tab` 返回上一词；最后一词按 `Tab` 聚焦提交按钮，不会自动提交。
- 拼写输入框获得焦点时自动播放对应单词读音，包括进入拼写阶段的第一词；也可点击播放按钮重听。

## ❓ 常见问题

- **双击 .command 打不开 / 提示权限**：右键 → 打开；或在终端执行 `chmod +x 启动背单词.command`。
- **端口被占用**：服务会自动顺延端口并在终端打印实际地址。
- **想换词库**：编辑 `data/words.json`（保持相同结构），或用「设置」里的导入功能。

## 收藏栏目

预习表、词表、已学单词与答题反馈均可收藏；在弹窗中多选“易记混”“拼写易错”“听音易错”“重点复习”，也可新增栏目。已收藏的词可重新编辑分类，收藏独立于错题本，答错只会自动加入错题本。收藏可按栏目筛选并按所选数量复习，分类随备份导出与恢复。

错题本与收藏分开存储、筛选、复习和移除，两者互不影响。旧数据迁移时，有错误记录的词保留在错题本，有分类或无错误记录的词移入收藏（有分类且答错的词会同时保留在两处）。
